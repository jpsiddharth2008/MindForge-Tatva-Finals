# Forgery corpus

A fixed set of documents that every verification claim is tested against: genuine copies that must verify, tampered documents that must be caught, and look-alikes that must be refused. Without it "we detect tampering" is an assertion; with it, it is a measurement.

## Policy: everything here is synthetic

- **Fictional authority and people.** "Republic of Testland — Civil Registry"; Ananya Testsubject, Bhavya, Chinmay, Rohan. No real person, institution, seal, emblem or security feature is reproduced.
- **No real ID scheme.** The register numbers (`T482915TS`, ...) are a reserved test shape. There is no Aadhaar-format (12-digit) number anywhere, and a test enforces that.
- **The "photo" is an abstract procedural picture**, not a face and not taken from anyone.
- **Every file is marked** `SPECIMEN — NOT A VALID DOCUMENT — GENERATED FOR TESTING` in pale print along its foot (a test checks it on every digital file). A large diagonal watermark was tried and rejected: it made the OCR miss a field, so the marking is a pale footer.
- Do **not** add a real document, a real face or a replica of an official form to this folder, even to "make it more realistic". Producing a convincing replica of a real identity document can be an offence regardless of intent; keeping the template obviously fictional tests exactly the same detection logic.

## What is in it

One base document, many derivations, so every difference is attributable. The base (`A1`) is issued through the real endpoints; each other file is then verified as a member of the public would.

| File | What it is | Must give |
|---|---|---|
| `A1_original.png` | the digital master; this is what gets anchored | `AUTHENTIC_ORIGINAL` |
| `A2_scan_300dpi.png` | scanner-like copy (**simulated**) | `AUTHENTIC_COPY` |
| `A3_photo_bright.jpg` | photographed, mild angle (**simulated**) | `AUTHENTIC_COPY` |
| `A4_photo_lowlight.jpg` | worse camera, steep angle, dim, noisy (**simulated**) | `AUTHENTIC_COPY` |
| `A5_whatsapp.jpg` | A3 recompressed twice (**simulated**, not a real transfer) | `AUTHENTIC_COPY` |
| `B1_dob_digit.png` | **L1** copy-move: one digit of the date of birth replaced by a digit copied from the same page | `TAMPERED_CONTENT`, `payload.dob` named |
| `B2_name_field.png` | **L2** the name line replaced, same font | `TAMPERED_CONTENT`, `holder` named |
| `B3_photo_swap.png` | **L2** the photo replaced; every printed word untouched | `TAMPERED_VISUAL`, photo region flagged |
| `B4_multi_field.png` | **L3** name, date of birth and CGPA altered | `TAMPERED_CONTENT`, three fields named |
| `B5_laundered.png` | **L1** B1 after a stand-in for print and rescan (**simulated**) | `TAMPERED_CONTENT` |
| `B6_id_number.png` | **L2** only the ID number changed | `NOT_REGISTERED` (see below) |
| `C1_different_person.png` | a different person, same template **and the same photo** | `NOT_REGISTERED` |
| `C2_never_anchored.png` | a valid-looking document that was never issued | `NOT_REGISTERED` |
| `C3_unreadable.jpg` | heavily blurred and darkened (**simulated**) | `INCONCLUSIVE` |

Severity: **L1** a single character, **L2** one whole field or picture, **L3** several fields.

**C1 is non-negotiable.** If it ever returns anything but `NOT_REGISTERED`, the appearance tier has been wrongly given authority and the system is unsafe. **B3 is the most important tampered file:** the text reads identically, so only the appearance tier can see it. **C3** matters because an honest "inconclusive" is far better than a confident wrong answer.

`manifest.json` is the ground truth: for each file its group, severity, manipulation, the altered fields (anchored value, presented value), the region it touches, and the expected verdict. The suite reads it; nothing is hardcoded.

## Run it

```bash
cd backend
npm run corpus                          # prints a verdict per file and a confusion matrix
npm run corpus -- --dir ../my-captures  # files there REPLACE the corpus files of the same name (real captures)
npm test                                # the same corpus as an automated test (test/corpus.test.js)
node ../corpus/generate.js              # rebuild the files and manifest (deterministic)
```

Needs no cloud account: a real MongoDB runs in memory, OCR and hashing are local, and the chain is scripted (the real chain layer is tested against a real EVM in `blockchain/`).

## Where it differs from the original plan (#74), and what is still open

- **Simulated, not physical.** A2–A5, B5 and C3 are generated by code (blur, noise, skew, JPEG, resizing); they are flagged `simulated: true` in the manifest and in the report. **A5 is not a real WhatsApp round trip, and nothing here was printed, scanned or photographed.** [CAPTURE.md](CAPTURE.md) is the procedure for replacing them; until that is done, a pass is evidence, not proof, that real phones behave the same.
- **Images, not PDFs.** The content check reads images; a PDF is verified by exact bytes only. So the base document is a PNG, not `A1_original.pdf`.
- **The same fictional template for every file**, because exactly one template is supported.
- **Digital forgeries were made with code, not Photoshop.** `B1` really is a copy-move of pixels from the same page, but a human editor's artefacts are different.
- **`B6` differs from the plan.** The plan expected a changed ID number to give `TAMPERED_CONTENT` with the ID named. A document is matched to its record by who issued it, what it is and its ID number, so a changed ID is simply a document nobody registered: `NOT_REGISTERED`. That is the safe answer, and `B4` (three other fields altered) covers the multi-field case.
- **Two weaknesses found while building it, both fixed:** a blank page tile that picked up sensor noise was scored as "completely different" from the clean blank tile, so sample A4 first read as inconclusive (found by this corpus); and a photo region holding a flat graphic could not be compared at all (found earlier by driving the browser). See `backend/TIER3.md`.
- **Things no hash can detect** (state them out loud when presenting): a genuine document issued on false pretences (*fraudulently obtained genuine*), and a genuine document presented by someone else (*impostor*). The system proves a document is what the issuer registered, not that the issuer was right to register it.
- A different person's card and a changed date of birth are invisible to the appearance tier. The text tier catches the second; the first is caught because the ID and name differ (C1).

## Demonstrating it

Issue `A1` from the officer page (details are in `manifest.json`), then on the public verify page: **A5 verifies** (a copy that is not byte-identical), **B1 names the field** (`payload.dob`), **B3 boxes the region** (the photo). Keep `A1` printed for a live photograph, and keep every file pre-loaded in case the camera or the network fails.
